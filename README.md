# Коротко о программе

Десктопное приложение для мониторинга и диагностики качества
интернет-соединения на основе телеметрии с роутеров.

Учебный проект. Не официальный продукт. Все данные синтетические.

---

## Возможности

- **Классификация** — OK / MEDIUM / CRITICAL по пороговым значениям
- **Статистика сети** — динамика статусов по минутам, рейтинг районов, средние метрики
- **Устройства** — таблица с фильтрами по периоду, адресу и статусу
- **Карточка роутера** — график и скользящее среднее, статистика за период, длительности в состояниях, вероятная причина сбоя
- **Карта** — точки по координатам, скопления проблем, массовые нарушения, расстояния до диспетчерского центра
- **Уведомления** — при трёх подряд CRITICAL, защита от дублей, звуковой сигнал
- **История** — обработанные оповещения с причинами
- **Рекомендации** — приоритеты действий с учётом критичности, длительности, района и массовости
- **Excel** — отчёты по устройствам, оповещениям, районам и рекомендациям
